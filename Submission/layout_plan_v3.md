# Submission Layout Plan V3

V3 的核心原则是以真实游戏截图为主视觉，不再把截图硬塞进模板框里。

## Poster Layout

- 主视觉：使用 `Submission/clean_screenshots/06_boss_combat_hero_crop.png` 作为大背景。
- 叙事证明：使用 `02_npc_dialogue_clean.png` 做“工坊记忆日志 / NPC 对话”区域。
- 底部截图条：使用 01、02、03、04、05、06 六张 clean 图。
- 标题区：左上深色遮罩，避免文字压在复杂截图上。
- Team / Demo Link：保留待回填位置，不伪造链接。

## Anti-Overlap Rules

- 文字不直接压在复杂截图上；封面使用深色侧栏。
- 每页保留大图，最多 4 个短文本块。
- 图片全部等比例缩放或裁剪，不拉伸。
- 装饰减少到最低，不再堆随机圆点和多层框。
