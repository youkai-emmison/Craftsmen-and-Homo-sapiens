# 能工智人：遗忘工坊 - Project Deck V3

## 1. 封面
能工智人：遗忘工坊 / Craftsmen and Homo Sapiens: The Forgotten Forge。

## 2. 游戏是什么
AI 叙事驱动的横版动作冒险：横版动作、房间推进、AI 记忆日志。

## 3. 核心玩法循环
进入房间 -> 读记忆日志 -> 战斗 -> 获得成长 -> 解锁下一房间 -> Boss -> 结局。

## 4. 角色与怪物
展示主角、NPC、普通怪、精英怪和 Boss 占位素材。

## 5. AI 叙事进入游戏
AI 生成世界观、房间日志、Boss 背景和结局文本，并通过 UI/对话进入游戏流程。

## 6. Demo 录屏路线
开场、日志、战斗、成长、Boss、Victory。

## 7. 技术结构
Unity 2D、Player、Combat、Enemy、Rooms、UI、Dialogue、WebGL。
