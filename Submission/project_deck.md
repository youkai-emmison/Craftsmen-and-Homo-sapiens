# 能工智人：遗忘工坊 - Project Deck V2

## 1. 封面
能工智人：遗忘工坊 / Craftsmen and Homo Sapiens: The Forgotten Forge。

## 2. 游戏是什么
AI 叙事驱动的横版动作冒险：横版动作、房间推进、AI 记忆日志。

## 3. 核心玩法循环
进入房间 -> 读记忆日志 -> 战斗 -> 获得成长 -> 解锁下一房间 -> Boss -> 结局。

## 4. 角色与怪物
展示主角、NPC、普通怪、精英怪和 Boss 占位素材。

## 5. AI 叙事如何进入游戏
AI 生成世界观、房间日志、Boss 背景和结局文本，并通过 UI/对话进入游戏流程。

## 6. Demo 录屏路线
0:00 开场，0:30 NPC/记忆日志，1:00 移动与战斗，2:00 成长反馈，3:00 Boss，4:00 Victory。

## 7. 技术与部署结构
Unity 2D、Player、Combat、Enemy、Rooms、UI、Dialogue、WebGL Build。

## 8. 亮点与提交状态
已完成海报/PPT/部署文档/素材整理/截图工具；待人工完成 WebGL 链接、Demo 视频、CodeBuddy 导出。
