# 3 分钟 Demo 视频脚本

## 视频目标

让评委在 3 分钟内看懂：

- 这是一个完整可玩的横版动作地牢 Demo。
- 项目选择的是“AI 重塑叙事体验”赛题。
- AI 参与了世界观、角色设定、房间日志、美术占位和代码开发。
- 玩家有明确目标：进入地牢、战斗、成长、击败 Boss。

## 0:00 - 0:15 标题与一句话介绍

画面：

- 展示游戏标题或开始界面。
- 展示项目名：能工智人 / Craftsmen and Homo sapiens。

旁白：

> 大家好，这是我们的腾讯云黑客松作品《能工智人》。它是一个 Unity 2D 横版动作地牢 Demo，选择赛题三：AI 重塑叙事体验。玩家将在 AI 档案重构的地下工坊中战斗、成长，并找回工匠与智人分裂的真相。

## 0:15 - 0:40 AI 世界观与操作说明

画面：

- 展示开场文本、NPC 对话或叙事面板。
- 展示操作提示。

旁白：

> 游戏中的世界观、房间档案、敌人设定和结局文本由 AI 辅助生成。我们把 AI 叙事做成了游戏内可见的档案记录，而不是只写在文档里。玩家可以用 A/D 移动，Space 跳跃，J 或鼠标左键攻击。

## 0:40 - 1:15 Early Room 战斗

画面：

- 玩家进入第一个房间。
- 击败 1 到 2 个弱小敌人。
- 展示血条、攻击反馈、敌人死亡。

旁白：

> 第一房间用于展示基础战斗。敌人是地下工坊中失控的低级构造体。玩家击败敌人后会获得经验或成长反馈，让评委能快速看到“打怪 -> 获得成长”的循环。

## 1:15 - 1:45 成长反馈

画面：

- 展示经验、等级、伤害或角色信息变化。
- 如果有背包或装备，可以短暂展示。

旁白：

> 为了适合比赛演示，我们把成长节奏压缩到了几分钟内。玩家在早期房间获得经验后，攻击力会明显提高，后面的敌人会被更快击败。

## 1:45 - 2:20 Mid Room 更强敌人

画面：

- 玩家进入第二房间。
- 展示更强敌人、飞行敌人或回血敌人。
- 展示玩家成长后打得更快。

旁白：

> 第二房间提高敌人强度，同时通过 AI 档案文本解释这些敌人原本是修复程序，如今变成了排斥活物的异常记录。玩法和叙事在这里合到一起。

## 2:20 - 2:50 Boss Room

画面：

- 玩家进入 Boss 房。
- 展示 Boss 或最终敌人。
- 展示战斗和击败过程。

旁白：

> 最终房间是 Demo Boss。它不是完整 Boss 系统，而是为了形成清晰的通关闭环：玩家进入核心区，击败守门人，完成本次档案回收。

## 2:50 - 3:00 Victory 与 AI 创作总结

画面：

- 展示 Victory / Demo Complete。
- 展示结局档案文本。

旁白：

> 击败 Boss 后，AI 档案给出结局文本：玩家既不是单纯的人类，也不是机械，而是能够记忆并继续创造的第三种答案。以上就是我们的黑客松 Demo。

## 录制检查

- [ ] 录制前关闭不必要的 Console 报错窗口。
- [ ] 视频中至少出现一次 AI 叙事文本。
- [ ] 视频中至少出现一次战斗、成长、Boss、胜利。
- [ ] 视频时长控制在 3 分钟以内。
- [ ] 片尾可以展示在线试玩链接和 GitHub 链接。
