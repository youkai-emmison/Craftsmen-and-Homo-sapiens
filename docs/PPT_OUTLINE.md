# 作品介绍 PPT 大纲

## 第 1 页：标题页

- 项目名：能工智人 / Craftsmen and Homo sapiens
- 赛事：AI CAN DO IT | 腾讯云黑客松游戏开发挑战赛
- 赛题：叙事类游戏 / AI 重塑叙事体验
- 团队成员：填写姓名与分工

## 第 2 页：一句话创意

标题：AI 档案重构的地下工坊冒险

内容：

- 玩家进入失控地下工坊。
- 通过横版动作战斗回收档案碎片。
- AI 生成的世界观和房间日志推动叙事。
- 击败 Demo Boss 后解锁最终真相。

## 第 3 页：赛题契合

说明本项目为什么属于叙事类游戏：

- 世界观由 AI 辅助生成。
- 房间文本和结局文本由 AI 辅助生成。
- NPC / 档案日志承担叙事功能。
- 玩家在战斗中逐步理解故事。

## 第 4 页：核心玩法循环

可放流程图：

`Start -> Early Room -> EXP / Level Up -> Mid Room -> Boss Room -> Victory`

说明：

- 移动、跳跃、攻击。
- 打怪获得成长。
- 房间清理后解锁门。
- Boss 被击败后 Demo 完成。

## 第 5 页：AI 创作内容

分三栏：

1. 世界观与剧情
   - 工匠 / 智人 / 智核 / 地下工坊。
2. 角色与敌人设定
   - Player、普通敌人、Demo Boss。
3. 美术与代码辅助
   - sprite sheet、图标、UI、Unity 脚本和调试。

## 第 6 页：技术架构

模块：

- Unity 2022.3 LTS
- Player Controller
- Combat / Enemy FSM
- Room Clear / Exit Door
- Inventory / Crafting / Device
- Dialogue / UI
- WebGL Build

可以放一张简化架构图。
