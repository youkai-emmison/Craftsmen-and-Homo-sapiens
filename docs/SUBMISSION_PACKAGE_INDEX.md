# 提交材料索引

本目录汇总腾讯云黑客松提交和答辩需要用到的文字材料。

## 核心材料

- `README.md`
  - 项目首页说明，适合放 GitHub 仓库首页。

- `docs/PROJECT_PROPOSAL_ZH.md`
  - 中文项目书，可复制到报名表、项目介绍文档或 PPT 备注。

- `docs/HACKATHON_SUBMISSION_CHECKLIST.md`
  - 提交前检查清单。

- `docs/AI_CREATION_LOG.md`
  - AI 创作说明，用于解释 CodeBuddy / AI 在项目中的作用。

- `docs/SUBMISSION_FORM_DRAFT.md`
  - 报名表、问卷、作品页可直接复制的中文文案。

- `docs/CODEBUDDY_EXPORT_GUIDE.md`
  - CodeBuddy 历史对话导出和最后一轮检查提示词。

## 展示材料

- `docs/DEMO_VIDEO_SCRIPT.md`
  - 3 分钟 Demo 视频脚本。

- `docs/PPT_OUTLINE.md`
  - 作品介绍 PPT 大纲。

- `submissions/Craftsmen_Hackathon_Deck.pptx`
  - 已生成的 10 页作品介绍 PPT 初稿，可继续补团队信息、试玩链接和 Demo 视频链接。

- `docs/WEBGL_DEPLOYMENT.md`
  - WebGL 构建与部署说明。

- `docs/ROADSHOW_QA.md`
  - 路演答辩可能被问到的问题和回答。

- `docs/SOCIAL_MEDIA_POST_DRAFTS.md`
  - 小红书、视频号、X、YouTube 等社交媒体发布文案草稿。

## 现有项目说明

- `docs/GAMEPLAY_DIRECTION.md`
  - 当前玩法方向。

- `docs/DEMO_STAGE_FLOW.md`
  - 三段式 Demo 流程。

- `docs/THIRD_PARTY_ASSETS.md`
  - 第三方素材和生成素材记录。

- `docs/NPC_DIALOGUE_GUIDE.md`
  - NPC 对话系统说明。

- `docs/GROUND_TURRET_DEVICE_GUIDE.md`
  - 机械炮台设备说明。

## 提交时还需要手动补齐

- 在线 WebGL 试玩链接。
- Demo 视频链接。
- PPT 文件中的团队信息、试玩链接和视频链接。
- CodeBuddy 历史对话导出文件。
- 社交媒体发布链接，可选加分项。
