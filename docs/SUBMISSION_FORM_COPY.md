## Project Description

```text
《能工智人：糖芯工坊》是一款 AI 叙事驱动的 2D 横版动作冒险游戏原型。玩家扮演一名意外穿越到糖果异世界的理工男，被系统误绑定为“见习女仆工程师”。为了回到现实世界，玩家需要在糖芯工坊中与 NPC 对话、学习技能、收集怪物掉落材料、合成装备与道具，并最终击败污染糖芯炉的 Boss。AI 辅助生成世界观、角色设定、NPC 对话、房间日志、Boss 背景与结局文本，并通过 NPC 对话和“糖芯工坊日志”进入游戏流程。
```
