## Project Description

```text
《能工智人：遗忘工坊》是一款 AI 叙事驱动的 2D 横版动作游戏原型。玩家扮演一名进入地下工坊遗迹的探索者，在被遗忘的工匠文明与智人文明冲突中寻找真相。游戏流程包含开场叙事、房间探索、近战战斗、经验成长、Boss 战与结局文本。AI 生成的世界观、角色设定、房间档案与结局记录会在游戏中以“工坊记忆日志”的形式呈现，使玩家在战斗推进中逐步拼合剧情。
```
