# Demo Recording Guide

本任务不录制最终 Demo 视频。此文档给负责录屏的同学使用。

## 推荐时长

3 到 5 分钟。

## 录制顺序

1. 标题 / 开场
   - 展示项目名：`能工智人：遗忘工坊`。
   - 简短说明赛道：叙事类游戏。

2. Intro / NPC 引导
   - 走近 NPC。
   - 打开对话框。
   - 展示“工坊记忆日志”叙事感。

3. 基础操作
   - 左右移动。
   - 跳跃。
   - 近战攻击。
   - 打开背包或制作面板，时间不要太长。

4. Combat / Room Clear
   - 击败普通敌人。
   - 展示血条、攻击反馈、房间推进。

5. Progression
   - 展示经验或成长反馈。
   - 如果技力条可见，展示自然恢复和技能消耗。

6. Boss Fight
   - 进入 Boss 房。
   - 展示 Boss 攻击和玩家反击。
   - 击败 Boss。

7. Victory / Ending
   - 展示 Demo Complete 或结局文本。
   - 结尾停留 2 到 3 秒，方便剪辑。

## 录屏前检查

- Unity Console 没有红色错误。
- Game 视图比例使用 16:9。
- 对话文字不乱码。
- UI 不遮挡角色。
- WebGL 版本或 Editor Play 版本都可以，但最终提交建议录 WebGL 链接。

## 不要录

- 不要录 Unity 编译等待过程。
- 不要录素材导入过程。
- 不要长时间停在 Inspector 或 Console。
- 不要展示未回填的 `localhost` 链接作为正式链接。
