## 页面长简介

```text
《能工智人 / Craftsmen and Homo sapiens》是面向 AI CAN DO IT | 腾讯云黑客松游戏开发挑战赛制作的 Unity 2D 横版动作地牢 Demo，选择赛题三：叙事类游戏 / AI 重塑叙事体验。

玩家进入一座由 AI 档案重构的地下工坊，在 Early Room、Mid Room 和 Boss Room 中移动、跳跃、攻击、击败异常敌人、获得成长反馈，并最终挑战 Demo Boss。

项目的重点不是接入实时 AI API，而是把 AI 辅助生成的世界观、房间档案、敌人设定和结局文本放进游戏体验里，让玩家通过战斗逐步读取“工匠”与“智人”分裂的真相。
```

## 操作说明

```text
A / D：左右移动
Space：跳跃
J 或鼠标左键：攻击
E：交互 / 推进 NPC 对话
I：打开或关闭背包
Esc：关闭部分面板或对话
```

## 推荐试玩路线

```text
1. 开场查看 NPC 对话或档案文本。
2. 进入 Early Room，测试移动、跳跃和攻击。
3. 击败敌人并观察成长反馈。
4. 进入 Mid Room，体验更强敌人。
5. 进入 Boss Room，击败最终目标。
6. 查看 Victory / Demo Complete / 结局档案文本。
```

## AI 使用说明

```text
本项目将 AI 用于三类内容：
1. 叙事创作：辅助生成世界观、房间档案、敌人与 Boss 设定、结局文本。
2. 美术辅助：辅助规划主角、怪物、道具、地图、UI 的占位视觉方向。
3. 编程协作：使用 CodeBuddy / AI 编程助手辅助 Unity C# 脚本、调试、文档和提交材料整理。
```
