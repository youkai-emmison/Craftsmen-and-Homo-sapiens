# CodeBuddy 提交材料检查清单

腾讯云黑客松要求提交 CodeBuddy 历史对话记录。这个文件用于最后导出前确认内容够用。

## 导出前先做一次 CodeBuddy 检查

把下面任务复制给 CodeBuddy，让它对当前项目做最后一轮提交前检查：

```text
你现在接手 Unity 2D 项目《能工智人 / Craftsmen and Homo sapiens》。

当前目标是腾讯云黑客松提交前最终检查。请只做检查、轻量修复建议和提交材料确认，不要大改玩法系统。

请检查：
1. 项目是否能说明自己选择了“赛题三：叙事类游戏 / AI 重塑叙事体验”。
2. README、项目书、AI 创作说明、PPT、Demo 视频脚本是否互相一致。
3. Unity 当前 Demo 是否有可演示闭环：移动、跳跃、攻击、敌人、成长、Boss、胜利。
4. WebGL 部署说明是否足够让队友操作。
5. 最终提交还缺哪些链接或文件。
6. 输出一份提交前问题清单。

不要新增复杂系统，不要改 ProjectSettings，不要导入第三方插件。
```

## 历史记录中最好能包含

- [ ] CodeBuddy 参与 Unity 项目检查。
- [ ] CodeBuddy 参与 C# 脚本或报错检查。
- [ ] CodeBuddy 参与 WebGL 部署流程梳理。
- [ ] CodeBuddy 参与 README、项目书、AI 创作说明、视频脚本或 PPT 检查。
- [ ] 对话中能看到项目名：能工智人 / Craftsmen and Homo sapiens。
- [ ] 对话中能看到赛题方向：AI 重塑叙事体验。

## 导出文件检查

- [ ] 文件能打开。
- [ ] 文件名包含项目名或 CodeBuddy。
- [ ] 文件中能看到 CodeBuddy 的实际建议或检查结果。
- [ ] 文件链接可以公开访问，或能随提交包一起上传。
- [ ] 链接已填写到 `submissions/FINAL_SUBMISSION_INFO.md`。
