# Demo 录屏执行清单

这个文件用于实际录制腾讯云黑客松 Demo 视频时逐项检查。目标是录出一条 3 分钟以内、评委能看懂的完整流程。

## 录制前准备

- [ ] 打开 Unity 项目并加载当前 Demo 场景。
- [ ] Console 没有红色 C# 编译错误。
- [ ] Player 能移动、跳跃、攻击。
- [ ] NPC 对话或档案文本能显示，视频里至少出现一次 AI 叙事内容。
- [ ] Early / Mid / Boss 流程能走通。
- [ ] 背包、制作、技力、炮台等面板不要挡住主流程，除非视频中需要展示。
- [ ] 录屏软件设置为 16:9，建议 1920x1080 或 1280x720。
- [ ] 关闭 QQ 弹窗、浏览器通知、Unity 多余 Inspector 面板遮挡。
- [ ] 准备好旁白稿：`docs/DEMO_VIDEO_SCRIPT.md`。

## 推荐录制节奏

### 0:00 - 0:15 标题和一句话介绍

- [ ] 展示游戏画面或标题画面。
- [ ] 说清楚项目名：能工智人 / Craftsmen and Homo sapiens。
- [ ] 说清楚赛题：赛题三，叙事类游戏 / AI 重塑叙事体验。

### 0:15 - 0:40 AI 叙事说明

- [ ] 展示 NPC 对话、档案文本或剧情提示。
- [ ] 说明 AI 辅助生成世界观、房间档案、敌人与 Boss 设定。
- [ ] 简短展示操作：移动、跳跃、攻击。

### 0:40 - 1:15 Early Room

- [ ] 玩家进入第一段区域。
- [ ] 击败 1 到 2 个弱小敌人。
- [ ] 展示敌人受击、血条或死亡反馈。
- [ ] 展示经验、升级或成长反馈。

### 1:15 - 1:45 Mid Room

- [ ] 进入第二段区域。
- [ ] 展示更强敌人或更多敌人。
- [ ] 说明玩家成长后击败敌人更快。
- [ ] 如果有炮台或制作物品，可以只展示一次，不要拖长。

### 1:45 - 2:30 Boss Room

- [ ] 进入最终房间。
- [ ] 展示 Boss 或最终目标。
- [ ] 展示玩家攻击、躲避、击败 Boss。
- [ ] 不要长时间空跑，必要时剪辑。

### 2:30 - 3:00 Victory 和总结

- [ ] 展示 Demo Complete / Victory / 结局档案文本。
- [ ] 总结 AI 叙事如何进入游戏体验。
- [ ] 片尾显示 GitHub 链接、WebGL 链接或项目名。

## 录制后检查

- [ ] 视频时长不超过 3 分钟。
- [ ] 视频里能看到：移动、跳跃、攻击、敌人、成长、Boss、胜利。
- [ ] 视频里能看到至少一次 AI 叙事文本或 NPC 对话。
- [ ] 画面没有明显黑屏、闪屏、遮挡。
- [ ] 声音清楚，旁白没有长时间停顿。
- [ ] 上传后链接可公开访问。
- [ ] 将视频链接填入 `submissions/FINAL_SUBMISSION_INFO.md`。
