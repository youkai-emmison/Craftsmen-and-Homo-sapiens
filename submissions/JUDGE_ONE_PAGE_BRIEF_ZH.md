# 《能工智人》评委单页摘要

## 30 秒看懂

《能工智人 / Craftsmen and Homo sapiens》是一个 Unity 2D 横版动作地牢 Demo，参赛方向为腾讯云黑客松赛题三“叙事类游戏 / AI 重塑叙事体验”。玩家进入由 AI 档案重构的地下工坊，在移动、跳跃、战斗、成长和 Boss 挑战中逐步理解“工匠”与“智人”分裂的真相。

## 核心演示流程

```text
开场 NPC / 档案提示
-> Early Room：熟悉移动、跳跃、攻击
-> 击败小怪，获得成长反馈
-> Mid Room：面对更强敌人，体现成长后战斗更快
-> Boss Room：击败 Demo Boss
-> Victory / Demo Complete
```

## AI 用在什么地方

- AI 叙事创作：生成地下工坊世界观、房间档案、NPC 台词、敌人和 Boss 设定。
- AI 美术辅助：规划主角、怪物、道具、地图、UI 等占位视觉方向。
- AI 编程协作：使用 CodeBuddy / AI 编程助手辅助 Unity C# 脚本、调试、文档、PPT 和提交材料整理。
