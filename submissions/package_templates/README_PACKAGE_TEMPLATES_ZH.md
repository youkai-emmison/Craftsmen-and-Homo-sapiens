# 上传包链接模板说明

这个目录存放最终压缩包里可以直接使用的链接说明模板。最终提交前，把这些文件复制到上传包对应目录里，并把 `TODO` 替换成真实链接。

推荐复制位置：

```text
Craftsmen_and_Homo_sapiens_Submission/
  03_Demo/
    WebGL_Link.txt
    Demo_Video_Link.txt
  04_CodeBuddy/
    CodeBuddy_History_Link.txt
  05_Source/
    GitHub_Link.txt
  06_BackupDocs/
    PPT_File_Link.txt
    Social_Media_Link_Optional.txt
```

使用顺序：

1. 先按 `submissions/LINKS_TO_FILL.md` 回填所有外部链接。
2. 再复制本目录中的 txt 文件。
3. 把每个 txt 文件里的 `TODO` 替换成真实链接。
4. 用无痕窗口检查链接是否能打开。
5. 最后再压缩上传包。

不要把本地路径、`localhost` 或需要登录权限的私密链接填进去。
